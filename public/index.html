Netlify Ticket Link Composer

Mint a login ticket, compose the authorize link, poll until approval, exchange for a token.

self-test
⚠ Authorized self-testing only. This composer builds a link that can authenticate a visitor and auto-approve an OAuth ticket in one click. Use it only against Netlify accounts you own, with a login_token issued to your own email address. Never deliver these links to another person. The exchanged token is unscoped: full API access, not read-only.
